# Keen Eye — новый режим «Память»

## Идея

Игроку показывают картинку **на 5 секунд**, затем она скрывается. Появляется **вторая картинка** — та же сцена, но с изменениями. Нужно найти изменения **по памяти**, не видя оригинал.

## Механика

1. **Запоминание** — показывается картинка A, крупно, на весь экран. Сверху таймер-полоска 5 секунд.
2. **Переход** — короткое затемнение/«шторка» (0,5 с), чтобы нельзя было сравнить кадры глазом.
3. **Поиск** — показывается картинка B. Игрок тапает по местам, которые изменились.
4. Найденное отмечается кружком. Тап мимо — промах.
5. **Конец уровня** — показывается картинка A рядом с B, все отличия подсвечены (и найденные, и пропущенные), чтобы игрок увидел, что упустил. Если раунд проигран на промахах (0 звёзд), ответ не показывается — B остаётся на экране, поверх окно «В этот раз не вышло» с «Заново» и «Меню», чтобы уровень можно было пройти снова по памяти. «Показать ответ» открывает ответ всегда.

## Правила

- Изменений на уровень: 3 в начале, до 5–6 на поздних.
- Время показа: 5 с на первых уровнях, 4 с — в середине, 3 с — на сложных.
- Промахи: максимум 3 (в спокойном режиме — без лимита).
- Подсказка «Взглянуть ещё раз»: снова показывает картинку A на 2 секунды (ограниченное число раз за уровень, например 1).
- Изменения должны быть заметными (предмет исчез/появился, сменил цвет, переместился) — мелкие детали по памяти не найти.
- Сцены проще, чем в основном режиме: 6–10 крупных объектов, среди которых 15 мелких декоративных (одинаковых на обеих
  картинках), чтобы изменения не бросались в глаза сразу.

## Типы изменений

- предмет исчез;
- появился новый предмет;
- изменился цвет;
- предмет переместился;
- изменилось количество (3 яблока → 2).

## Структура уровней

- Отдельная категория «Память» на экране категорий.
- 15 уровней: 1–5 — 3 изменения / 5 с; 6–10 — 3 изменения / 4 с; 11–15 — 4 изменения / 3 с.
- Первые 3 уровня бесплатные, остальные — «Полная версия».
- Мультяшный стиль, офлайн, без рекламы.

## Данные уровня (пример)

```json
{
  "id": "memory-01",
  "mode": "memory",
  "showSeconds": 5,
  "imageA": "levels/memory/01-a.svg",
  "imageB": "levels/memory/01-b.svg",
  "peeks": 1,
  "differences": [
    { "x": 0.30, "y": 0.55, "r": 0.07, "type": "removed", "label": "ведро" },
    { "x": 0.72, "y": 0.40, "r": 0.06, "type": "color", "label": "дверь" }
  ]
}
```

Координаты — в долях ширины/высоты картинки (0–1).

## Звёзды за уровень

- 3 звезды — все найдены, без подсказки, ≤ 1 промаха;
- 2 звезды — все найдены;
- 1 звезда — найдено больше половины.

## Реализация

- Уровни 301–330 — категория `memory` (`MEMORY_CHAPTER` в `src/levels/chapters.ts`), файлы `src/levels/memory/level-NNN.ts`.
  Картинки — SVG, нарисованные кодом (`memoryLevel` + `diff` в `src/levels/helpers.ts`, фигуры в `src/levels/memory/shapes.ts`),
  а не файлы `01-a.svg`/`01-b.svg`: зоны регистрируются там же, где рисуется отличие, поэтому координаты всегда совпадают
  с объектом, а `npm run check-levels` проверяет, что A и B различаются только внутри зон и каждая зона видна.
  Координаты — в единицах viewBox, а не в долях. Картинки вертикальные, 500×750 (`MEMORY_VIEWBOX` в `helpers.ts`;
  `room`, `daySky`, `hills`, `ground` из `memory/shapes.ts` берут размер оттуда): A и B показываются по одной, и на телефоне
  в вертикальном положении картинка занимает почти весь экран. В конце раунда A и B стоят рядом при любой ориентации.
- 316–330 — более насыщенные сцены (12–18 объектов с мелкими деталями): 316–320 — 4 изменения / 5 с,
  321–330 — 5 изменений / 4 с; на такую картинку нужно чуть больше времени, чем на сцены 311–315.
- Изменение «переместился» — одна зона, накрывающая оба места; «изменилось количество» — зона на всю группу.
- Декор (полки, банки, картинки, облака, камни, ракушки…) — общие фигуры из `memory/shapes.ts`, `time/shapes.ts` и фигур
  глав; он одинаков на A и B и держится не ближе 20 единиц к зонам отличий.
- Движок раунда — `src/engine/memory-scene.ts` (`MemoryScene`), экран — `src/views/MemoryLevelView.vue` (`/memory/:id`).
- Конец раунда: все найдены, последний промах или кнопка «Показать ответ». Промахов (сердечек в шапке) на 2 меньше,
  чем изменений на уровне: 1 при 3 изменениях, 2 при 4, 3 при 5 (`MODE_RULES.normal.memoryMaxMisses`); в спокойном
  режиме промахи не ограничены. Уровень засчитан при ≥ 1 звезде
  (в спокойном режиме — когда найдено всё). Подсказка «Взглянуть ещё раз» в спокойном режиме — 3 раза за попытку.
