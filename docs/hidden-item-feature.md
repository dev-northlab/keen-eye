# Keen Eye — фича «Скрытый предмет главы»

## Идея

В каждой главе (категории или деле) спрятан **один секретный предмет** — например, маленький золотой ключ. Он находится в одной из сцен главы, **не входит в число отличий** и не учитывается для прохождения уровня. Найти его могут только самые внимательные. Собрав ключи из всех глав, игрок открывает **бонусную сцену**.

## Где применяется

- Обычные категории: Ферма, Город, Лес, Море, Космос — каждая = глава.
- Новые режимы (Время, Память, Путешествие, Детектив) — по одному ключу на главу/регион/дело.
- Режим «Память» — ключ можно прятать только в картинке поиска (B).

## Механика

- Ключ есть **только в одном** уровне главы, на одной из двух картинок (или на обеих в одном месте — решить на этапе дизайна; по умолчанию — на обеих, чтобы не путать с отличием).
- Ключ маленький (примерно 2–3% ширины картинки), частично прикрыт объектами, но честно виден — без пиксельной охоты.
- Тап по ключу: анимация (блеск, ключ улетает в счётчик), звук, сообщение «Секретный ключ найден!».
- Тап по ключу **не считается** промахом и не засчитывается как отличие.
- Лупа-подсказка **никогда** не указывает на ключ.
- Уровень можно пройти, не найдя ключ. Позже можно вернуться и поискать.
- Без намёков, в каком уровне главы спрятан ключ (опционально: после прохождения всей главы — тонкий намёк «Ключ где-то в уровнях 3–5»).

## Прогресс и награда

- На экране категорий у каждой главы — иконка ключа: серая (не найден) / золотая (найден).
- Общий счётчик: «Ключи: 3 / 8».
- Все ключи собраны → открывается **бонусная сцена** «Сокровищница» (особый уровень с большим числом отличий, необычной красивой картинкой и анимацией открывающегося сундука).
- Ключи из платных глав доступны только в полной версии — это дополнительная мотивация к покупке; в бесплатной части должен быть хотя бы 1 ключ (в Ферме), чтобы игрок узнал о фиче.
- Прогресс сохраняется локально, офлайн.

## Данные (пример)

```json
{
  "id": "farm-07",
  "imageA": "levels/farm/07-a.svg",
  "imageB": "levels/farm/07-b.svg",
  "differences": [ ... ],
  "secret": { "id": "key-farm", "x": 0.83, "y": 0.62, "r": 0.03, "on": "both" }
}
```

- `secret` есть только у одного уровня в главе.
- `on`: `"a"`, `"b"` или `"both"`.
- Зона тапа ключа чуть больше картинки ключа, но не пересекается с зонами отличий.

## Бонусная сцена

- Тема: сокровищница / чердак с сундуками.
- 8–10 отличий, анимированные элементы.
- Открывается сундук → поздравление «Вы — самый внимательный игрок!».
