# Keen Eye — новый режим «Путешествие по миру»

## Идея

Игрок путешествует по миру: каждый уровень — узнаваемая сцена города или страны в мультяшном стиле (поиск отличий, как в основной игре). После прохождения локации показывается **короткий интересный факт** о ней.

## Механика

- Обычный поиск отличий: две картинки, 5–7 отличий.
- Сцены построены на узнаваемых символах места: архитектура, природа, транспорт, еда, одежда, животные.
- Отличия по возможности связаны с местной тематикой (у гондолы другой цвет, у кактуса нет иголок и т.п.).
- После уровня — карточка «Знаете ли вы?» с фактом (1–2 предложения), флагом/иконкой страны и кнопкой «Дальше».
- Пройденные места отмечаются на карте мира (простая мультяшная карта со «штампами в паспорте»).

## Структура

Регионы → страны/города → уровни.

| Регион | Примеры локаций |
|--------|-----------------|
| Европа | Париж, Рим, Венеция, Лондон, Амстердам |
| Азия | Токио, Пекин, Индия (Агра), Таиланд |
| Кавказ | Ереван, Баку, Тбилиси |
| Америка | Нью-Йорк, Мексика, Бразилия (Рио) |
| Африка | Египет (пирамиды), Кения (сафари), Марокко |
| Океания | Сидней, Новая Зеландия |

- Старт: 15 уровней (по 2–3 на регион), дальше расширять.
- Первые 3 уровня бесплатные, остальные — «Полная версия».
- Сложность растёт по мере продвижения.
- Офлайн, без рекламы, мультяшный стиль.

## Правила для фактов

- Коротко: 1–2 предложения, понятно детям и взрослым.
- Только проверенные, общеизвестные факты (без спорных цифр и политики).
- Позитивный, интересный тон.
- Пример: «Эйфелеву башню строили как временное сооружение для выставки 1889 года — её собирались разобрать через 20 лет».
- Тексты на русском, с возможностью перевода (i18n).

## Данные уровня (пример)

```json
{
  "id": "travel-paris",
  "mode": "travel",
  "region": "europe",
  "country": "France",
  "city": "Париж",
  "imageA": "levels/travel/paris-a.svg",
  "imageB": "levels/travel/paris-b.svg",
  "differences": [
    { "x": 0.50, "y": 0.20, "r": 0.06, "label": "флаг на башне" }
  ],
  "fact": "Эйфелеву башню строили как временное сооружение для выставки 1889 года.",
  "mapPos": { "x": 0.48, "y": 0.30 }
}
```

Координаты — в долях 0–1.

## Экраны

1. Карта мира — регионы и открытые локации.
2. Уровень — поиск отличий.
3. Карточка факта — после победы.
4. «Паспорт» — коллекция штампов пройденных мест.

## Реализация

- Уровни 401–432 — категория `travel` (`TRAVEL_CHAPTER` в `src/levels/chapters.ts`), файлы `src/levels/travel/level-NNN.ts`.
  Как и в остальной игре, картинки — рисованные SVG-сцены (`travelLevel` поверх `svgLevel`): отличия задаёт `diff(x, y, r, a, b)`
  в координатах viewBox 800×500, поэтому зона всегда совпадает с нарисованным объектом, а `npm run check-levels` это проверяет.
  Вместо отдельных `imageA`/`imageB` и долей 0–1 — одна сцена на обе картинки.
- Место уровня — `Level.travel`: регион, код страны (флаг из `src/levels/travel/flags.ts`), широта и долгота (точка на карте мира
  вместо `mapPos`). Название места — `levelTitles.<title>`, факт — `worldTravel.facts.<title>`, во всех языках интерфейса.
- 15 мест: Европа (Париж, Венеция, Амстердам), Азия (Токио, Агра, Великая Китайская стена), Кавказ (Ереван, Баку, Тбилиси),
  Америка (Нью-Йорк, Рио-де-Жанейро), Африка (Гиза, сафари в Кении), Океания (Сидней, Южные Альпы Новой Зеландии).
- Сложность: 401–405 — 5 отличий, 406–410 — 6 (до одного в движении), 411–415 — 7 (одно в движении, зоны мельче и дальше друг от друга).
- Ещё 15 более сложных городов (416–430), по правилу «одна страна — один город»: Европа (Лондон, Барселона, Афины, Прага,
  Стамбул), Азия (Дубай, Бангкок, Сингапур, Сеул), Африка (Марракеш, Кейптаун), Америка (Торонто, Мехико, Куско,
  Буэнос-Айрес). 416–420 — 8 отличий, 421–425 — 9, 426–430 — 10; в каждом одно в движении, зоны мельче (r ≥ 18).
- Москва (431, Европа) и Астана (432, Азия) — тоже по 10 отличий.
- Уровни открываются по порядку, первые 3 бесплатные (как у «Время» и «Память»).
- Экраны: баннер «Путешествие по миру» в режимах игры → карта мира `/travel` (регионы, места, прогресс) → уровень (`LevelView`);
  после победы в окне результата — «Знаете ли вы?» с флагом и фактом, при первом прохождении — «Новый штамп в паспорте!»;
  паспорт `/travel/passport` — штампы пройденных мест, по нажатию снова показывает факт.
