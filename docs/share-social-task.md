# Задание для Claude Code: «Поделиться» и соцсети в Keen Eye

## Промпт (скопируй в Claude Code)

```

Прочитай файл share-social-task.md в корне проекта и выполни задание целиком.
Сначала изучи структуру проекта (роутер, экраны, стили, где экран завершения уровня),
затем внеси изменения в существующем стиле кода. Игра должна работать офлайн.

```

---

## Что нужно сделать

### 1. Зависимости
```bash
npm install @capacitor/share @capacitor/browser simple-icons
npx cap sync
```

### 2. Конфиг ссылок — `src/config/links.js`
- `APP_NAME = 'Keen Eye'`
- `STORE_LINKS = { android, ios }`
  - android: `https://play.google.com/store/apps/details?id=<PACKAGE_NAME>` — взять appId из `capacitor.config.*`
  - ios: `null`, пока приложения нет в App Store
- `SOCIAL_LINKS` — массив `{ name, url, icon }` с заглушками (ЗАМЕНИТЬ ПОЗЖЕ):
  - Instagram — `https://instagram.com/CHANGE_ME`
  - TikTok — `https://tiktok.com/@CHANGE_ME`
  - Telegram — `https://t.me/CHANGE_ME`
  - YouTube — `https://youtube.com/@CHANGE_ME`
- Функция `getStoreLink()`: на iOS возвращает ios-ссылку, если она есть, иначе android.
- Пустые ссылки (`null`) в UI не показывать.

### 3. Composable — `src/composables/useShare.js`
- `shareApp(text?)` — вызывает `Share.share({ title, text, url: getStoreLink(), dialogTitle })`.
- Текст по умолчанию: «Попробуй найти все отличия! 👀».
- Если пользователь закрыл меню — молча игнорировать ошибку.
- В браузере (dev-режим): если `navigator.share` нет — копировать ссылку в буфер и показать короткое уведомление «Ссылка скопирована».
- `openLink(url)` — `Browser.open({ url })`.

### 4. Компоненты
- `src/components/ShareButton.vue` — кнопка «📤 Поделиться», проп `text` (необязательный).
- `src/components/SocialLinks.vue` — ряд круглых кнопок с SVG-логотипами из `simple-icons` (inline SVG, без загрузки из сети), подпись под каждой, `aria-label`. Размер касания не меньше 44×44 px.
- Стиль — мультяшный, в общей стилистике игры (скруглённые углы, яркие цвета, как у существующих кнопок).

### 5. Экран «О игре» — `src/views/AboutView.vue`
- Название и иконка игры, версия (из `package.json`).
- Кнопка «Поделиться игрой».
- Блок «Мы в соцсетях» с `SocialLinks`.
- Кнопка «Оценить игру» → открывает ссылку магазина.
- Добавить маршрут `/about` и кнопку перехода на него из главного меню/настроек (иконка ℹ️).

### 6. Шеринг после уровня
- На экране завершения уровня добавить `ShareButton` с текстом:
  «Я нашёл все отличия на уровне {N} в Keen Eye! 🎉 Сможешь быстрее?»
- Кнопка не должна мешать основным кнопкам «Дальше» / «Меню».

### 7. Требования
- Все тексты — на русском; если в проекте есть i18n, вынести строки туда.
- Никакой рекламы и трекеров.
- Игра работает офлайн; при отсутствии интернета кнопки соцсетей просто открывают браузер (ошибки не показывать).
- Не ломать существующие уровни 1–15 и прогресс.

### 8. Проверка
- `npm run build` без ошибок.
- `npx cap sync`.
- Проверить в браузере: экран «О игре» открывается, кнопки работают, после уровня видна кнопка шеринга.
