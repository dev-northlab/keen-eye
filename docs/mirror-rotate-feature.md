# Keen Eye — фича «Зеркало и поворот»

## Идея

На поздних уровнях вторая картинка показывается **отзеркаленной или повёрнутой**. Сцена та же, отличия те же, но сравнивать глазами намного сложнее. Это усложнение без новых картинок — подходит для поздних уровней любой категории.

## Варианты трансформации

| Тип | Описание | Сложность |
|-----|----------|-----------|
| `mirror-x` | зеркало по горизонтали (лево ↔ право) | средняя |
| `mirror-y` | зеркало по вертикали (верх ↔ низ) | высокая |
| `rotate-180` | поворот на 180° | высокая |
| `rotate-90` / `rotate-270` | поворот на 90° (только если картинка квадратная) | очень высокая |

По умолчанию для старта: `mirror-x` и `rotate-180` — они не меняют пропорции картинки и хорошо смотрятся на телефоне.

## Механика

- Картинка B — тот же SVG, что и обычно, но с CSS/SVG-трансформацией при отображении. **Новых картинок рисовать не нужно.**
- Координаты отличий в данных хранятся **в исходной (нетрансформированной) системе**, как сейчас.
- При тапе по картинке B координаты тапа переводятся обратно через обратную трансформацию и сравниваются с зонами отличий.
- Кружок найденного отличия рисуется на B в трансформированной позиции (т.е. в том месте, где игрок его видит), на A — как обычно.
- Лупа-подсказка также учитывает трансформацию.
- Перед первым таким уровнем — короткая плашка: «Внимание! Вторая картинка отражена» (с иконкой). Бейдж с иконкой (🪞 / 🔄) виден на уровне всё время.
- Текст, цифры и вывески на картинке тоже отразятся — это нормально и добавляет сложности. Если важно, можно не использовать уровни с текстом.

## Где применять

- Последние 5 уровней каждой категории (например, 16–20 в Ферме из 20): чередовать `mirror-x` и `rotate-180`.
- Можно сделать отдельный переключатель «Сложный режим» в настройках: применяет случайную трансформацию к любым пройденным уровням — бесплатная реиграбельность.
- Не применять к режимам «Память» и «Отличия во времени» на старте (там и так сложно).

## Данные (пример)

```json
{
  "id": "farm-18",
  "imageA": "levels/farm/18-a.svg",
  "imageB": "levels/farm/18-b.svg",
  "transformB": "mirror-x",
  "differences": [
    { "x": 0.20, "y": 0.40, "r": 0.05 }
  ]
}
```

`transformB`: `"none"` (по умолчанию), `"mirror-x"`, `"mirror-y"`, `"rotate-180"`, `"rotate-90"`, `"rotate-270"`.

## Преобразование координат (для долей 0–1)

| Тип | Показ (исходная → экран) | Тап (экран → исходная) |
|-----|--------------------------|-------------------------|
| mirror-x | (1−x, y) | (1−x, y) |
| mirror-y | (x, 1−y) | (x, 1−y) |
| rotate-180 | (1−x, 1−y) | (1−x, 1−y) |
| rotate-90 | (1−y, x) | (y, 1−x) |
| rotate-270 | (y, 1−x) | (1−y, x) |

Логику вынести в одну утилиту (например, `transformPoint` / `inverseTransformPoint`) и покрыть тестами.
