# Keen Eye — новый режим «Детективная история»

## Идея

Игрок — сыщик. Каждое найденное отличие — **улика**. Уровни объединены в **главы-дела**: в конце главы игрок собирает улики и «раскрывает дело», выбирая виновного. Сюжет даёт причину играть дальше и мотивирует купить полную версию, чтобы узнать, чем всё закончится.

## Механика

- Обычный поиск отличий (две картинки, 5–7 отличий) на месте преступления.
- Каждое отличие — улика с коротким описанием: «Следы грязных сапог», «Окно открыто», «Пропал ключ».
- Найденные улики попадают в **блокнот детектива**.
- В конце главы — **экран раскрытия дела**: 3–4 подозреваемых, игрок выбирает виновного, опираясь на улики.
- Правильный ответ — сцена-развязка и звезда «Дело раскрыто». Неправильный — мягкая подсказка, можно попробовать снова (без наказания).
- Мультяшный стиль, лёгкий и добрый тон: без насилия, «преступления» бытовые и забавные (пропал торт, украли сыр, кто-то разбил вазу).

## Структура

- Глава = дело = 4–5 уровней (сцен) + финальный экран раскрытия.
- Старт: 3 дела (15 уровней).
- **Дело 1 — бесплатное полностью** (крючок).
- Дело 2 — первые 2 уровня бесплатные, затем замок «Полная версия» с текстом: «Узнайте, кто виноват — откройте полную игру».
- Дело 3 и далее — полная версия.

## Примеры дел

| Дело | Сцены | Подозреваемые |
|------|-------|----------------|
| Пропавший торт | кухня, сад, гостиная, чердак | кот, повар, сосед, собака |
| Тайна сырной лавки | лавка, склад, улица, подвал | мышь, торговец, ворона, мальчик-разносчик |
| Разбитая ваза в музее | зал, коридор, кладовка, двор | смотритель, турист, попугай, уборщик |

Каждый подозреваемый должен «подходить» под часть улик, но только один — под все.

## Экраны

1. Список дел (обложки, статус: не начато / в процессе / раскрыто / закрыто).
2. Вступление к делу — 2–3 предложения сюжета.
3. Уровень — поиск отличий; при находке всплывает карточка улики.
4. Блокнот детектива — все улики дела.
5. Раскрытие дела — выбор подозреваемого.
6. Развязка — короткий итог и награда.

## Данные (пример)

```json
{
  "id": "case-cake",
  "title": "Пропавший торт",
  "intro": "Утром торт исчез со стола. Кто его взял?",
  "free": true,
  "suspects": [
    { "id": "cat", "name": "Кот Мурзик" },
    { "id": "dog", "name": "Пёс Бобик" }
  ],
  "culprit": "dog",
  "ending": "Это был Бобик — крошки на усах выдали его!",
  "levels": [
    {
      "id": "case-cake-1",
      "imageA": "levels/detective/cake-1-a.svg",
      "imageB": "levels/detective/cake-1-b.svg",
      "differences": [
        { "x": 0.40, "y": 0.70, "r": 0.06, "clue": "Следы лап у стола" }
      ]
    }
  ]
}
```

Координаты — в долях 0–1. Прогресс (улики, раскрытые дела) сохраняется локально, офлайн, без рекламы.

## Реализация

- Категория `detective` (`DETECTIVE_CHAPTER` в `src/levels/chapters.ts`), уровни 501–515 в `src/levels/detective/`:
  3 дела по 5 сцен — «Пропавший торт» (501–505, бесплатно), «Тайна сырной лавки» (506–510), «Разбитая ваза в музее»
  (511–515); по 5 → 6 → 7 улик на сцену. Первое дело бесплатно целиком (`freeLevels: 5`), остальные — «Полная версия».
- Сцены — SVG (`detectiveLevel`), слева «как было», справа «как стало». Каждое отличие рисуется через
  `clue(key, x, y, r, a, b)`: зона регистрируется как у `diff`, поэтому `npm run check-levels` проверяет, что она точно
  совпадает с нарисованным предметом.
- `cases.ts`: подозреваемые, виновный и `fits` — кому подходит каждая улика. Тест (`tests/detective.test.ts`) проверяет,
  что под все улики дела подходит ровно один подозреваемый — виновный, а каждый из остальных подходит хотя бы под одну.
- Неверное обвинение показывает улику, которая не подходит выбранному подозреваемому; штрафа нет.
- Экраны: `/detective` — список дел со статусом (не начато / в процессе / раскрыто / полная версия), `/detective/:case` —
  вступление, сцены, блокнот улик, подозреваемые и развязка; при находке в уровне всплывает карточка улики.
- Раскрытые дела хранятся локально в `progress` (`cases`), тексты — `detective.*` во всех 21 языке.
