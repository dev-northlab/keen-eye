# Keen Eye — новый режим «Отличия во времени»

## Идея

Игроку показывают **одну и ту же сцену в два разных момента времени**:
- утро ↔ вечер (ночь);
- лето ↔ зима;
- (позже) весна ↔ осень, ясно ↔ дождь, «до» ↔ «после» праздника.

Многое на картинках меняется **естественно** — свет, тени, листва, снег, горящие окна, одежда, луна вместо солнца. Это **не** отличия.

Задача игрока — найти то, что **не должно было измениться**, но изменилось:
- другое число окон у дома;
- флюгер повёрнут в другую сторону на неподвижной крыше;
- у забора стало меньше досок;
- вывеска с другим текстом/цветом;
- дерево переехало на другое место;
- цвет двери или почтового ящика другой;
- у кота другой окрас;
- исчезла/появилась труба, камень, скамейка.

Главная фишка — **ловушки**: естественные изменения отвлекают, и тап по ним засчитывается как ошибка (мягкая — без жёсткого штрафа в спокойном режиме).

## Механика

- Две картинки рядом (или одна над другой на телефоне), как в основном режиме.
- 5 «настоящих» отличий на уровень в начале, 6–8 на поздних уровнях.
- 3–6 «ложных» изменений (сезонные/суточные) — тап по ним показывает подсказку: «Это просто вечер — так и должно быть» и считается промахом.
- Подсказка (лупа) подсвечивает зону с настоящим отличием.
- Стиль — мультяшный, как во всей игре.
- Работает офлайн, без рекламы. Первые уровни бесплатные, остальные — в полной версии.

## Типы пар

| Пара | Что естественно меняется (ловушки) |
|------|-------------------------------------|
| Утро ↔ Вечер | небо, солнце/луна, длина теней, свет в окнах, фонари, звёзды |
| Лето ↔ Зима | листва, снег, сосульки, одежда, лёд на пруду, снеговик, птицы |
| Ясно ↔ Дождь (позже) | лужи, зонты, тучи, мокрые крыши |

## Структура уровней

- Отдельная категория «Время» на экране выбора категорий.
- 15 уровней: 1–5 «Утро/Вечер», 6–10 «Лето/Зима», 11–15 смешанные, сложнее.
- Сцены: ферма, улица города, лес, пристань, двор.

## Данные уровня (пример)

```json
{
  "id": "time-01",
  "mode": "time",
  "pair": "day-night",
  "imageA": "levels/time/01-morning.webp",
  "imageB": "levels/time/01-evening.webp",
  "differences": [
    { "x": 0.42, "y": 0.31, "r": 0.05, "label": "окно" }
  ],
  "traps": [
    { "x": 0.70, "y": 0.10, "r": 0.08, "hint": "Это просто луна — вечером так и должно быть" }
  ]
}
```

Координаты — в долях ширины/высоты картинки (0–1), чтобы не зависеть от размера экрана.

лето/зима). Естественные изменения (свет, тени, снег, листва, луна, огни

   и сложнее (5 отличий в начале, до 7–8 в конце, 3–6 ловушек).

   объектами.
8. Всё офлайн, без рекламы и внешних запросов.
9. Адаптивность: на узком экране картинки одна над другой.
10. Тексты интерфейса — на русском (и в i18n, если она уже есть в проекте).
