# Keen Eye — 3D-картинки «Путешествий» (уровни 401–432)

План и правила для 3D-версий (стиль «Новый», `docs/redesign-pictures.md`) всех 32 мест режима «Путешествия»
(`docs/world-travel-mode.md`). Документ самодостаточный: по нему в любой следующей сессии собирается набор промптов
для Gemini, проверяется пара картинок и подключается уровень. Решения пользователя — с датами.

## Решения (2026-11-13)

1. **Число отличий = как в нарисованном уровне** (`check-levels` сверяет): 401–420 — 8, 421–425 — 9, 426–432 — 10.
   В 401–415 их было 5 → 6 → 7; 2026-11-13 подняли до 8 и в SVG-версии (добавлены в основном природа: цветы, птицы,
   деревья), чтобы весь режим шёл ровно 8–10.
2. **3D сложнее нарисованной версии: только мелочи.** Каждое отличие — маленькая часть предмета (флажок на мачте, ручка
   амфоры, рожки жирафа, одна гроздь, одна шишечка на крыше), а не целый крупный предмет. Отличия 3D-картинки **не
   обязаны совпадать по смыслу** с SVG-уровнем — у картинок свои зоны; совпадает только количество. Смысл SVG-отличия
   берём, если он уже мелкий; крупный (перекрасить весь паром, убрать снег с вершины) заменяем мелкой частью рядом.
3. **Ровно одна перекраска на уровень**, остальное — убрать / добавить маленькую часть. Без поворотов и отражений
   (Gemini их не делает). Отличие в движении SVG-уровня становится неподвижным (картинки не двигаются).
4. **Достопримечательность — узнаваемая, как в жизни** (пользователь, 2026-11-13: «yes»): настоящие пропорции,
   материалы и детали (кованое железо Эйфелевой башни, мрамор Тадж-Махала, медные шары Кутубии), но композиция —
   по эскизу: те же места в кадре, тот же порядок слева направо.
5. **Много природы** (пользователь, 2026-11-11 и 2026-11-13): в каждом промпте A абзац «Fill it with nature» —
   растения и животные именно этого места (сакура и белоглазки в Токио, олеандр и гранат в Баку, протея и пингвины
   в Кейптауне, жакаранда в Буэнос-Айресе), цветы, птицы, бабочки, дальний пейзаж в дымке.
6. **Свет и сезон — свои у каждого места** (пользователь, 2026-11-13: «do what you want»): всегда светлое время
   суток, без ночи; сезон и час — в плане уровня ниже. Москва — зимой со снегом.
7. **Стиль — как у 203 и 211–213** (понравился пользователю): настоящая 3D-сцена с глубиной, как кадр дорогого
   анимационного фильма, а не плоская перерисовка эскиза. Люди мелкие, с естественными пропорциями. Без текста, букв и
   цифр (вывески, таблички, номера — пустые или с узором).
8. **Зоны.** Отличия разбросаны по всей картинке (небо, середина, передний план), не кучкой и не все на
   достопримечательности. Зона — круг r ≥ minRadius × ширина картинки / 800 (`check-levels`): на 2624 px это 79 px
   для 401–405, 73 для 406–410, 66 для 411–415 и 60 с 416; зоны не пересекаются. Две правки на одном предмете — только если они далеко друг от друга.
9. **Ключ.** «Путешествия» прячут ключ на уровне 409 (Тбилиси, у бань). Gemini рисует золотой ключик на A на месте
   эскиза, наполовину прикрытым; в B он на месте. Дальше — как в `docs/redesign-pictures.md`: вырезать в
   `level-409-key.webp`, закрасить его место на A и B, записать в `secret`.

## Как делать партию

1. **Образцы.** Рендер A каждого уровня партии с лишними объектами обычного режима (они остаются на картинке) в
   `~/Downloads/keen-eye-redesign-kit/level-NNN-reference-a.png`, 1600×1000. Скрипт — во временной папке сессии:

   ```ts
   // node ref.ts <out dir> <id> ...
   import { writeFileSync } from 'node:fs'
   import { allLevels } from '/home/develop/Desktop/Game/keen_eye/src/levels/index.ts'
   import { posedSvg, rasterize } from '/home/develop/Desktop/Game/keen_eye/scripts/render.ts'
   const [out, ...ids] = process.argv.slice(2)
   for (const id of ids.map(Number)) {
     const level = allLevels.find((l) => l.id === id)!
     const { w, h } = level.viewBox
     const s = 2
     const png = rasterize(`<g transform="scale(${s})">${posedSvg(level.build!(0, 0, true), 0)}</g>`, w * s, h * s).asPng()
     writeFileSync(`${out}/level-${id}-reference-a.png`, png)
   }
   ```

2. **Промпты.** `PROMPTS-NNN-MMM.md` в той же папке: шапка (как в `PROMPTS-326-330.md`: один чат на уровень,
   образец к промпту A, B в том же чате, файлы в `keen_eye/assets/test/`), затем по каждому уровню PROMPT A и PROMPT B
   из шаблонов ниже и плана уровня. Перед отдачей проверить: каждая часть из списка B названа в A; перекраска одна;
   число правок = числу отличий уровня.
3. **Проверка пары** (пользователь кладёт A и B в `assets/test/`): B сверяю с планом попиксельно, лишнее возвращаю
   с A, пропущенное дорисовываю (приёмы — в `docs/redesign-pictures.md`). Зоны меряю по разнице, исходники — WebP в
   полном размере в `~/Pictures/keen-eye/levels/redesign/level-NNN-a|b.webp`, затем
   `npm run encode-pictures -- ~/Pictures/keen-eye`. B — вырезками (`patchesB: zonePatches(...)`), если изменения не
   выходят за зоны; иначе целиком.
4. **Подключение.** `src/levels/travel/level-NNN-redesign.ts` (образец — `travel/level-401-redesign.ts`: в комментарии —
   что сделал Gemini и что поправлено руками) и `redesign` в уровне. **`travelLevel` (helpers.ts) раньше не передавал
   `redesign` в `svgLevel`** — добавлено 2026-11-13 (уровень 401). Потом `npm run check-levels -- NNN`.
   Исходники из `assets/test/` удалить, не коммитить без просьбы.

## Шаблоны промптов

PROMPT A (подставить место, свет, список объектов, природу, части и материалы):

> Turn this flat sketch into a beautiful, natural, realistic photo-like 3D scene of {PLACE}, like a frame from a
> high-end animated film. Real depth, not a flat side view: the camera a little above the ground looking slightly
> {down/up}, {the ground/street/water} going back into the distance with perspective, far layers fading in soft haze,
> every object with volume, its own soft shadow and contact with the ground, a gentle depth of field. Make
> {LANDMARK} look exactly like the real one — its true shape, proportions, materials and details — but keep it where
> the sketch has it. Keep the objects of the sketch in the same places in the frame and in the same left-right order:
> {OBJECTS, with every part that will change named in CAPITALS}.
> Fill it with nature: {NATURE}. Keep every new object clear of {THE PARTS}: they stay fully visible and uncovered.
> {LIGHT}, realistic materials: {MATERIALS}. People small, with natural proportions. No text, no letters or numbers
> on signs, boats, buses or flags.
> Make the image as large as possible: 2K resolution (about 2600×1600 pixels), landscape 16:10, sharp and detailed.

PROMPT B (тот же чат):

> Edit this image. Keep the same size in pixels, the same framing and camera, every object at exactly the same pixel
> position and size. Do not crop, zoom, stretch or move anything. Change only these {N} small parts:
> 1. … (каждая строка — одна часть одного предмета, названного по месту: «the LEFT palm», «the middle lantern»,
>    и что остаётся: «keep the mast»)
> Change nothing else: keep every other object with the same shape, colour and size, the same number of {birds,
> clouds, people, boats, …}. Do not add, remove, move or redraw anything that is not in this list.

Если B пришёл перерисованным целиком или другого размера — в том же чате: «Change only those parts, keep everything
else exactly as in the previous image, pixel for pixel, same size». Если осталась тень убранной части — «Remove also
the shadow where the … was».
