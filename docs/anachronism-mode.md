# Keen Eye — режим «Найди лишнее» (анахронизмы)

## Идея
Одна мультяшная картинка исторической эпохи. В ней спрятаны предметы, которых в эту эпоху быть не могло (смартфон у рыцаря, самолёт над пирамидами). Игрок тапает по ним. После находки показывается короткий факт: что это и когда появилось.

## Цели прототипа
- 1 уровень: «Древний Египет», 5–6 лишних предметов.
- Переиспользовать текущий движок уровней: лупа/зум, прогресс, сохранения, спокойный режим без таймера.
- Работа офлайн, без рекламы. Vue 3.

## Формат данных уровня
Координаты — в процентах от размера изображения (0–100), чтобы не зависеть от экрана.

```json
{
  "id": "egypt-01",
  "mode": "anachronism",
  "world": "time-travel",
  "era": "Древний Египет",
  "image": "levels/time-travel/egypt-01.png",
  "difficulty": 1,
  "items": [
    {
      "id": "plane",
      "shape": "circle",
      "x": 72, "y": 12, "r": 6,
      "label": "Самолёт",
      "fact": "Первый полёт самолёта — 1903 год, братья Райт."
    },
    {
      "id": "phone",
      "shape": "rect",
      "x": 30, "y": 55, "w": 5, "h": 7,
      "label": "Смартфон",
      "fact": "Смартфоны с сенсорным экраном стали массовыми после 2007 года."
    }
  ]
}
```

Поля:
- `shape`: `circle` (x, y, r) или `rect` (x, y — левый верхний угол, w, h).
- `label` — короткое название, `fact` — 1 предложение, проверенный факт.

## Механика
1. Показ одной картинки на весь доступный экран; зум/пан и лупа как в обычном режиме.
2. Тап → перевод координат экрана в проценты изображения с учётом зума/сдвига.
3. Попадание в хитбокс (с запасом +20% к размеру) → отметка кружком, всплывающая карточка `label + fact`, счётчик «найдено N из M».
4. Повторный тап по найденному — ничего.
5. Промах: в спокойном режиме — лёгкая анимация «мимо», без штрафа; в обычном — опционально −очки/время.
6. Все найдены → экран победы, список всех предметов с фактами, переход дальше.
7. Подсказка: подсвечивает область одного ненайденного предмета.

## Компоненты (Vue 3, Composition API)
- `AnachronismLevel.vue` — экран уровня, загрузка JSON, состояние.
- `useHitTest.ts` — перевод координат и проверка попадания (circle/rect), чистые функции.
- `FactCard.vue` — всплывающая карточка факта.
- Переиспользовать существующие: зум/лупа, прогресс, сохранение, экран победы.
- Регистрация режима в общем загрузчике уровней по полю `mode`.

## Правила контента
- Лишние предметы рисуются в том же мультяшном стиле, что и сцена.
- Сложность растёт: сначала крупные и очевидные, затем мелкие и тонкие (часы, очки, бутылка).
- Только бесспорные анахронизмы; каждый факт проверять.
- Эпохи на будущее: Египет, Рим, викинги, средневековый замок, пираты, Дикий Запад, каменный век.

## Тесты
- Юнит-тесты для `useHitTest` (попадание/промах, границы, запас хитбокса, учёт зума).
- Проверка, что уровень загружается и завершается при нахождении всех предметов.

## Готово, когда
- Уровень «Египет» проходится от начала до конца на телефоне.
- Существующие уровни «Ферма» работают без изменений.
