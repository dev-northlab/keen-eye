# Keen Eye — режим для двух игроков

Игра офлайн и без рекламы, поэтому основа — **локальная игра на одном устройстве**. Онлайн вынесен в «позже» как отдельный этап.

## 1. Режимы

| Режим | Как играют | Устройство |
|---|---|---|
| **Дуэль (Duel)** | Оба ищут отличия на одной паре картинок одновременно, кто нашёл первым — тот получает очко | Один планшет/телефон, экран повёрнут горизонтально, каждый игрок со своей стороны |
| **По очереди (Hot-seat)** | Игроки ходят по очереди: у каждого N секунд или до первой ошибки | Один телефон, передают друг другу |
| **Кооператив (Co-op)** | Вместе ищут все отличия, общий счёт и общий таймер/жизни | Одно устройство |
| *Онлайн (позже)* | Дуэль по сети | Два устройства, нужен сервер или Bluetooth/Wi-Fi Direct |

## 2. Раскладка экрана (Дуэль)

```
┌─────────────── ГОРИЗОНТАЛЬНО ───────────────┐
│  [Игрок 1: 3]                  [Игрок 2: 2] │
│ ┌────────────┐            ┌────────────┐    │
│ │ Картинка A │            │ Картинка B │    │
│ └────────────┘            └────────────┘    │
│   зона касаний P1           зона касаний P2 │
└─────────────────────────────────────────────┘
```

- Вариант 1 (проще): обе картинки общие, касание засчитывается тому, **на чьей половине экрана** оно было.
- Вариант 2 (для планшета «лицом к лицу»): у каждого игрока своя копия пары картинок, у верхнего — повёрнута на 180°.
- Цвет маркеров: Игрок 1 — синий, Игрок 2 — красный.

## 3. Правила

- Найденное отличие закрывается для обоих, очко получает нашедший.
- Ошибочный клик: штраф — блокировка касаний на 2 сек (не минус очки, чтобы детям было не обидно).
- Победа: больше очков после того, как найдены все отличия. Ничья возможна.
- Подсказки в дуэли отключены (или по 1 на игрока — настройка).
- Таймер — опционально, по умолчанию выключен (соответствует спокойному режиму игры).

## 4. Уровни для мультиплеера

- Используются **уже пройденные или бесплатные** уровни (1–15), чтобы режим работал и без покупки.
- После покупки — все уровни.
- Желательно больше отличий (7–10), чтобы игра длилась дольше: можно взять уровни из 2-го мира и выше или добавить флаг `multiplayerReady` в level.json.

## 5. Данные

```json
// match state
{
  "mode": "duel | hotseat | coop",
  "levelId": 12,
  "players": [
    { "id": 1, "name": "Игрок 1", "color": "#3B82F6", "score": 0, "lockedUntil": 0 },
    { "id": 2, "name": "Игрок 2", "color": "#EF4444", "score": 0, "lockedUntil": 0 }
  ],
  "found": [{ "diffIndex": 0, "byPlayer": 1, "at": 12.4 }],
  "currentTurn": 1,
  "status": "playing | finished"
}
```

История матчей (победы по именам) — в localStorage.

## 6. Экраны

1. Главное меню → кнопка **«Вдвоём»**
2. Выбор режима (Дуэль / По очереди / Вместе)
3. Ввод имён (необязательно) и выбор цвета
4. Выбор уровня (или «случайный»)
5. Игра
6. Итоги: победитель, счёт, кнопки «Реванш» / «Другой уровень» / «Меню»


## 8. Позже: онлайн

- Самый простой путь — WebSocket-сервер (Node) с комнатами по коду из 4 цифр.
- Без сервера — Wi-Fi Direct / Bluetooth через Capacitor-плагины (сложнее, особенно на iOS).
- Онлайн нарушает принцип «полностью офлайн», поэтому делать его отдельной опцией.
