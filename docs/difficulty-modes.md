# Keen Eye — уровни сложности: «Спокойный» и «Обычный»

Реализовано. Правила режимов — `MODE_RULES` в `engine/rules.ts`, переключатель — `settings.mode`.

## Идея

Игроку нужен выбор сложности, но рисовать отдельные версии уровней не нужно. Сложность — это **правила поверх тех же
уровней**: подсказки, цена ошибки, звёзды, лишние объекты на картинке. Сами уровни уже усложняются по мере прохождения
(`levels/difficulty.ts`, «сложная десятка» в конце каждого мира, декор в «Времени» и «Памяти»).

| Режим | Для кого | Что это |
|---|---|---|
| Спокойный | дети, расслабленная игра | без таймера, ошибок, блокировки и звёзд; 3 подсказки на попытку; чистые картинки |
| Обычный | большинство | 1 подсказка на попытку, звёзды; на картинках лишние объекты (`docs/extra-objects.md`) |

Был и третий режим, «Сложный» (без подсказок, проигрыш на второй ошибке, красные звёзды). Его убрали: три режима —
лишний выбор, а вызова хватает и в обычном. Его лишние объекты перешли в обычный режим; красные звёзды и проигрыш по
ошибкам ушли вместе с ним. Сохранённые красные звёзды (`hard` в прогрессе) и режим `hard` в настройках при загрузке
отбрасываются: настройка становится «Обычным».

## Правила

Все числа — в `MODE_RULES` (`engine/rules.ts`). Сцены получают их через свои опции, экраны читают оттуда же и не
проверяют режим на месте.

| Что | Спокойный | Обычный |
|---|---|---|
| Подсказки (заново на каждой попытке) | 3 | 1 |
| Ошибки | не считаются | влияют на звёзды |
| Блокировка за 3 быстрых промаха (`MissGuard`) | нет | 3 с |
| «Время»: тап по ловушке | промах + пояснение | промах + пояснение |
| «Память»: «Взглянуть ещё раз» | 3 на попытку | `peeks` (1) |
| «Память»: промахи до конца раунда | без лимита | 3 |
| Лишние объекты (`extras`) | нет | да (кроме «Памяти») |
| Картинка B зеркальная или повёрнутая (`transformB`) | нет, как нарисована | да |
| Скорость анимации | 0.6 | 1 |
| Звёзды | нет | `computeStars` / `memoryStars` |

## Прогресс

- Звёзды — результат обычного режима (`progress.records`).
- Прохождение в спокойном режиме засчитывает уровень пройденным без звёзд (`stars: 0`). Порядок открытия и покупка не
  меняются.

## Где переключать

- Настройки и главный экран: переключатель «Спокойный / Обычный» (`settings.mode`), выбранная кнопка — в цвете режима
  (`--mode-calm`, `--mode-normal`). Режим читается при старте уровня; другой режим, выбранный в настройках меню паузы,
  начинает уровень заново.
- На экране уровня рядом с номером — плашка режима попытки (`ModeChip`).

## Какие режимы игры затрагивает

| Режим игры | Режимы сложности | Комментарий |
|---|---|---|
| Миры, «Время», «Путешествия», «Детектив», сокровищница (`LevelView`) | да | общие правила |
| «Память» (`MemoryLevelView`) | да | плюс правила «Памяти»; без лишних объектов |
| «Найди лишнее» (`AnachronismLevelView`) | да | подсказки, блокировка, звёзды |
| «Малыш» (`LevelView`) | нет | всегда по правилам спокойного, но с одной подсказкой |
| Двое игроков (`/duo`) | нет | у дуэлей свои правила |

## Не делаем

- Отдельные версии уровней или сцен для режимов.
- Режимы сложности в дуэлях.
- Обратный отсчёт до времени на три звезды.

## Открыто

С лишними объектами обычный режим стал труднее: `parTimeSec` уровней стоит проверить на нескольких уровнях каждого
режима игры, особенно на поздних уровнях с 9–10 отличиями.
